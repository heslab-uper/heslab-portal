Climate Outlook — run Okt 2026

Kajian riset HESLab atas prakiraan musiman ECMWF SEAS5 run Okt 2026: indeks ENSO (Niño3.4) dan IOD (DMI) enam bulan ke depan, peluang El Niño, La Niña, dan IOD per bulan, serta anomali suhu muka laut di sekitar Indonesia.

Arsip kajian run Okt 2026 (diolah 15 Okt 2026). Halaman ini tidak berubah dan dapat dikutip. Kajian run terbaru: Climate Outlook.

Bukan prakiraan resmi. Halaman ini adalah pembahasan ilmiah atas satu run model global untuk keperluan riset dan edukasi. Prakiraan iklim resmi Indonesia diterbitkan oleh BMKG.

    Sumber dan pengolahan data

    Produsen data
    ECMWF SEAS5 (system 51) melalui Copernicus Climate Change Service (C3S) Climate Data Store (laman dataset ↗)
    Produk
    Prakiraan musiman bulanan, 51 member, lead 1–6 bulan (lead 1 = bulan awal run); terbit sekitar tanggal 5 setiap bulan.
    Pengolahan
    Anomali Niño3.4 dan DMI dihitung terhadap klimatologi SEAS5 1991–2020 per bulan awal dan lead, lalu dikalibrasi linear ke ONI (NOAA CPC) dan DMI (NOAA PSL, HadISST); rerata SEAS5 (raw) ditampilkan berdampingan. Kelas per lead = bagian member: La Niña ≤ −0,5 / El Niño ≥ +0,5 °C, IOD− ≤ −0,4 / IOD+ ≥ +0,4 °C. Peta: anomali SST rerata ensemble per sel 1° terhadap klimatologi SEAS5 1991–2020 yang sama.
    Keterbatasan
    Prakiraan musiman menggambarkan peluang, bukan kepastian, dan keterampilannya menurun dengan lead time. Informasi iklim resmi Indonesia tetap mengacu pada BMKG.
